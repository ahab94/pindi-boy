# Pindi Boy: videos

Build: `bash tools/video/record_footage.sh` then `/usr/bin/python3 tools/video/make_videos.py`, which writes to `build/videos/`.
Every Short is true 9:16 at 1080x1920, 60 fps, mixed to −14 LUFS, with the game's own sound plus the ride theme and stingers.
The end card says "Free browser game, coming soon, @ahab94" until there's a play link. Once the game is live, swap in the link (Shorts description links aren't clickable).

All uploads go up Private first for the user to review. The name "Pindi Boy" is still a working title.
