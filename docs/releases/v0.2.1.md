# Pindi Boy v0.2.1

- **Touch buttons no longer overlap.** On later rides (with all four grabs plus PATAAKHA), the trick buttons ran into JUMP on phones held upright. All buttons now sit in a compact strip below the road: two rows on a tall phone, one row in landscape. Each small button takes the first free spot, and a new test checks every ride, in the air and with SCENE ON, on six phone and tablet shapes, so no two buttons overlap and none leaves the screen.
